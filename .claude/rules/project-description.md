# Project description

This project is meant to serve as a build calculator for heroes, synergy pairs and overall team compositions in the game Dispatch.

It provides an interface that displays an overview of the whole team with all the extra controls to adjust each hero.

Additional setup flags are available, such as those to define who was cut in episode 3 and who was added in episode 4.

While the aim is not to show any bias, some tips may be provided to help users make the best use of the game's mechanics.

Users can save, load and share their builds.
